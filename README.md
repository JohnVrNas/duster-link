# Duster Link

App do celular para a central **Duster OS**: manda velocidade, GPS, clima e bateria para o tablet do carro pelo Bluetooth.

## [Baixar o Duster Link](https://github.com/JohnVrNas/duster-link/releases/latest/download/duster-link.apk)

Depois de instalar, abra o app e toque em **Configurar tudo**.
